## 📌 Project Overview

The **PDF Merger Application** is a backend service built using **Node.js** and **Express.js** that allows users to upload multiple PDF files and merge them into a single downloadable document.

The application provides secure API endpoints for file uploads, efficient server-side PDF processing, and automatic file cleanup after download.

---

## ✨ Key Features

- 📂 Upload multiple PDF files  
- 📑 Merge PDFs into a single document  
- 🔐 Secure file handling using Multer middleware  
- 🧹 Automatic deletion of temporary files  
- 📥 Download merged PDF  
- 🌍 Deployed on Render  

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **Multer**
- **pdf-merger-js**
- **Render (Deployment)**
